# Store Ratings

A full-stack web application for managing and rating registered stores. Users can rate stores from 1 to 5 stars, store owners can view ratings, and administrators can manage users and stores.

## Features

- User registration and login
- Role-based access: Admin, Normal User, Store Owner
- Browse and search stores
- Submit and update 1–5 star ratings
- Store owner rating dashboard
- Admin dashboard
- User and store management
- JWT authentication

## Tech Stack

- **Frontend:** React.js, Vite, Axios, React Router
- **Backend:** Node.js, Express.js, Sequelize
- **Database:** MySQL
- **Deployment:** Railway
